Next.js frontend for Velora.

```bash
npm install
npm run dev
```

Runs on [http://localhost:3000](http://localhost:3000) and expects the FastAPI
backend on port 8000. Override with `NEXT_PUBLIC_API_URL` and
`NEXT_PUBLIC_WS_URL` if it lives somewhere else.

Setup for the whole project, including the backend and the seed step, is in the
[root README](../README.md).
